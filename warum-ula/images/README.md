# “Warum ULA?” gallery assets

These assets are prepared from local legacy-gallery originals. Both formats use
the same uncropped composition, normalized orientation, sRGB color, and stripped
metadata. JPEG files are progressive at quality 85; WebP files use quality 82.
The 800×533 originals remain at their native size, while the 2000×1333 originals
are reduced to 1600×1066.
